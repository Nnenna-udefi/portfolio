## 🛠️ Tech Stack

- **Framework & Core:** Reactjs,
- **Styling & UI:** CSS3, framer-motion, fontawesome
- **Deployment:** Vercel

---

## 🗺️ Core Sections

- **👤 About Me:** A brief background on who I am, my development philosophy, and the skills I bring to the table.
- **💼 Services:** A breakdown of what I offer, focusing on strategy-first branding, scalable web design, and conversion-optimized growth tools.
- **🚀 Projects:** A curated gallery showcasing live web applications I have engineered—from full-stack platforms to bulk utilities and AI-driven tools.
- **📬 Contact Me:** A streamlined contact portal for inquiries, freelance collaboration, and professional networking.

---

## 🛠️ Local Development

To spin up this portfolio locally:

1. **Clone the repository**

```bash
   git clone [https://github.com/nnennaudefi/portfolio.git](https://github.com/nnennaudefi/portfolio.git)
   cd portfolio
```

2. **Install dependencies**

```bash
npm install
```

3. **Run the development server**

```bash
npm run dev
```

Head over to http://localhost:3000 to view the live local site.
